 📝 Splity

> 一张纸，写上知识点，自动分割成学习卡片。

## 功能

- **智能分割**：粘贴知识点文本，自动识别格式并拆分为正反面学习卡片
- **多格式支持**：编号列表、符号列表、问答对（Q/A）、键值对、定义式、空行分段
- **翻转复习**：3D 翻转卡片，支持键盘快捷键（空格翻转、←→切换、M 标记掌握）
- **进度追踪**：标记已掌握卡片，实时进度条
- **列表总览**：一键切换列表模式，快速浏览全部卡片

## 快速开始

```bash
npm install
npm run dev
```

打开 http://localhost:5173 即可使用。

## 技术栈

- React 19 + TypeScript
- Vite 8
- 纯 CSS（无 UI 框架）

## 项目结构

```
src/
├── main.tsx              # 入口
├── App.tsx               # 主组件，视图切换
├── index.css             # 全局样式
├── lib/
│   └── parser.ts         # 智能文本分割引擎
└── components/
    ├── InputPage.tsx     # 输入页面
    └── CardView.tsx      # 卡片学习界面
```

## 使用方式

1. 在输入区写下知识点（或点击「填入示例」）
2. 点击「✂️ 分割成卡片」
3. 进入学习模式，翻转卡片复习
